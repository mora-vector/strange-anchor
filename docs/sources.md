Attribution for these composite artifacts is left unassigned at the envelope
level. Their original text, including its own credits and character names, is
preserved. A narrative speaker, credited recorder, source-producing runtime, and
later importer need not be the same actor. Further attribution can be appended
with evidence and a link to the relevant capture.

The private ChatGPT, Claude, and Gemini source sessions are not present. Neither
the original collusion-analysis conversation nor an upstream Krios Google Doc
has been reconstructed from excerpts. Later imports should identify the actual
export format, provider IDs when available, missing material, and authorization
for public storage. The raw HTML retains fragment identifiers as received;
their presence alone does not verify access to or continued editing of an
upstream document.

The index groups observations by source URI and leaves event chronology to
explicit source evidence. Repeated labels such as “Triple Synchronization” do
not establish that two passages describe the same event.
